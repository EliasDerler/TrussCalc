# TrussCalc

TrussCalc ist ein Windows-Desktopprogramm zur Berechnung von Aluminium-Traversen
in der Veranstaltungstechnik.

## Download

Die aktuelle Windows-Version liegt als ZIP-Datei in den GitHub Releases:

https://github.com/EliasDerler/TrussCalc/releases/latest

ZIP entpacken und `TrussCalc.exe` im entpackten Ordner starten. Die Dateien im
Ordner `_internal` werden von der Anwendung benötigt und müssen neben der EXE
bleiben.

Eine ausführliche Anleitung steht in [INSTALLATION.md](INSTALLATION.md).

## Updates

Beim Start prüft TrussCalc, sofern eine Internetverbindung besteht, ob eine neue
Programmversion oder neue Einträge in der Default-Traversenbibliothek im Public
Repository verfügbar sind.
